## 2) Layer Prompt Template

Use one prompt per layer:

`Photorealistic [subject], isolated cutout, crisp edge separation, neutral studio lighting, realistic texture, high detail, editorial photography, clean silhouette, no stylized illustration artifacts, transparent or plain removable background.`

Add topic-specific details after `[subject]`.

## 3) Master Prompt Template

`Editorial infographic collage illustration about [TOPIC], photoreal cutout composition, grayscale base with [ACCENT_COLOR] highlights, realistic business-news documentary tone, layered circular backplates, subtle halftone and paper grain textures, clear foreground-midground-background depth, balanced negative space for headline/callout, clean typographic label placeholders, cohesive lighting direction, high detail, print-ready composition.`

## 4) Negative Prompt Template

`cartoon, painterly, watercolor, low-resolution, blurry faces, malformed hands, inconsistent perspective, oversaturated colors, chaotic clutter, fantasy lighting, anime style, plastic skin, distorted typography, random gibberish text, duplicate limbs, bad anatomy`

## 5) Composition Checklist

Before finalizing, verify:

- One dominant focal subject is obvious in 2 seconds.
- Accent color appears in 10-25% of the composition.
- Foreground subjects do not merge into background value.
- At least one texture layer is visible but subtle.
- Key message can be inferred without reading text.
- If text exists, it is short and functional (headline/callout only).

## 6) Fast Variant Knobs

Produce 3 rapid variants by changing only one axis each:

1. **Color variant:** switch accent color while preserving layout.
2. **Density variant:** simplify or increase object count.
3. **Framing variant:** wide, square, or vertical crop from same composition logic.
